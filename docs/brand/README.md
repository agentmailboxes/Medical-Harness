# Monochrome logo

![Proposed monochrome mark](monochrome-concept.png)

Generated with the built-in OpenAI image generation tool on 2026-10-12 after Adobe Express returned service errors, then approved by the project owner. The silhouette is adapted into the lightweight editable SVG at `static/assets/brand/m-mark.svg`, used by the header and assistant avatar, with a matching favicon. CSS masks let the avatar follow the current theme. The original raster is preserved here as the design reference; it is not downloaded by the app. No stock or squirrel illustration was used. A generated concept does not establish trademark exclusivity.

Prompt:

> Create one original logo concept for medical-harness, a calm and precise evidence-based health research assistant. Category logo-brand. A minimal compact abstract lowercase m symbol: two interlocking rounded arches, elegant asymmetric negative-space gap expressing clarity and connected evidence. Solid warm-white mark on pure black. Absolutely flat vector-like 2D silhouette, crisp edges and moderate weight, legible at 24 pixels, quietly distinctive. Centered symbol occupies 65% of square image with generous surrounding space. No book icon, no squirrel, no medical cross, no heartbeat, no green or other colors, no gradient, no shadow, no text, no mockup. This is a separate proposed logo concept; do not include any existing brand logo.
